# ☕Project Title
## Brew Haven — Premium Coffee Shop Website

# Project Description
## Brew Haven is a modern and responsive coffee shop website developed using HTML, CSS, and JavaScript.

## The website is designed with a luxury dark theme and provides an attractive user interface for coffee lovers.

## The project includes multiple pages such as Home, Login, Register, Shop, Cart, Payment, Success, and Logout pages.

## It also contains animations, hover effects, responsive layouts, and interactive navigation to create a smooth user experience.


# Features  of the Project

## -Navigation bar with multiple pages
## -Coffee menu showcase
## -Login and Register pages
## - Cart and Payment pages
## -Payment success page and Logout functionality
